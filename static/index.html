    Voice & settings

    ⚠ With Azure selected, essay text is sent to Microsoft's speech service to generate audio. Choose “Windows voices” to keep everything on this machine. See README for key setup.

    Changing voice or sliders regenerates audio the next time you press play.

    Pronunciation fixes

    When the voice mangles a name, add it here — e.g. read “Keneally” as “Kuh-nee-lee”. Fixes apply to the audio for every essay; the text on screen never changes.
